# Impulse responses (not in git)

The breach mix (`src/scp-mariah/breach.sfx.json`) uses three impulse responses from the
EchoThief library (https://www.echothief.com/). The files are not in git: the EchoThief
license permits their use for the creative works of individuals, but not for video
production intended for wide distribution or in software for distribution without a
commercial license from the SDSU Research Foundation.

To get them, download `EchoThief.zip` from the site and copy these files here:

| File here | File in EchoThief | T30 (measured) |
| --- | --- | --- |
| `battery-randol.wav` | `Underground/Battery Randol Fort Worden Historical State Park Port Townsend Washington.wav` | 2.7 s |
| `command-post.wav` | `Underground/Harbor Entrance Command Post Fort Worden Historical State Park Port Townsend Washington.wav` | 2.4 s |
| `graffiti-hallway.wav` | `Brutalism/Graffiti Hallway UC San Diego California.wav` | 2.1 s |

The Fort Worden spaces are concrete coastal artillery bunkers. For a public release,
replace these with impulse responses under an open license.
